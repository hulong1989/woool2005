# GameServer 重建骨架 —— 构建与运行

这是 2005 年《传奇世界》风格服务端快照（原工程名 `chuanqiServer`，路径 `D:/chuanqiServer`）的**可编译重建版**。
原始快照只有服务端逻辑层 40 个 `.cpp/.h`，缺少引擎公共层和 7 个工程文件；本目录补齐了这些缺失件，使其能够编译、启动、接受连接并跑通角色/地图/物品主流程。

在“能编译”之后，又补了**快照中完全没有的玩法基础**：本地角色存档、伤害/死亡/复活、怪物与简单 AI（第 9 节），
参考《传奇世界》的**三职业、等级经验与技能**（第 10 节），
**药品、自然恢复、商店、第二张地图与传送**（第 11 节），
**NPC 实体与对话/商店/传送**（第 12 节），**物品堆叠与技能书学习**（第 13 节）、**任务系统**（第 14 节），
**装备强化/拆分、组队/行会、矿洞与 Boss**（第 15-17 节），
**Boss 定时刷新、任务链/日常、NPC 对话树**（第 18-20 节），
**行会等级/权限与活动系统**（第 21-22 节），**行会仓库与等级增益**（第 23 节）、**多掉落表、仓库权限、活动排期**（第 24-26 节），
**可交互图形客户端**（第 27 节），**沃玛寺庙副本与小地图**（第 28 节），**地图/装备/怪物/NPC 内容扩展**（第 29 节），**套装属性与 Boss 首杀**（第 30-31 节），**装备附魔/洗炼**（第 32 节），**世界 Boss 排期**（第 33 节），**组队副本「沃玛神殿」**（第 34 节）、**副本排行榜/首通奖励**（第 35 节），
**副本多实例并行**（第 36 节），**副本怪物独立重置**（第 37 节），**成就/称号系统**（第 38 节），**客户端战斗表现**（第 39 节），**称号加成/成就点数**（第 40 节），以及**称号商店/收集面板、副本难度分级、客户端贴图音效**（第 41-43 节），
**尸王殿/蛇魔谷副本**（第 44 节），**矿洞/将军坟副本与 PNG 图集**（第 45 节），**副本专属套装/首通称号**（第 46 节），**祖玛寺庙/图鉴/像素美术**（第 47 节），**全副本地狱档/图鉴奖励**（第 48 节），**分副本排行/图鉴称号**（第 49 节），**排行赛季结算**（第 50 节），以及**逆魔古刹/禁地副本与动画帧**（第 51 节）。

> 重建的边界、依据、对原代码的每一处改动，见 [docs/RECONSTRUCTION.md](docs/RECONSTRUCTION.md)。
> 原始 GBK 源码完整备份在 `original_gbk/`（未改动）。

## 2. 构建

### macOS / Linux（已验证）

```bash
make          # 生成 build/GameServer
make run      # 直接运行
make client   # 启动图形客户端（另开终端）
make client-test  # 客户端 headless 验收
make clean
```

要求：支持 C++11 的 clang++ / g++。当前在 macOS + Apple clang 21 上 **0 error / 0 warning**。

### Windows（MSVC，脚本未在本机实测）

```bat
build.bat
```

请在 “x64 Native Tools Command Prompt for VS 2017+” 中执行。要点：`/utf-8`（源码为 UTF-8）、链接 `ws2_32.lib winmm.lib`。

### Windows（MinGW）

```bash
make CXX=g++ LDFLAGS="-lws2_32 -lwinmm"
```

> `compat/` 只在非 Windows 下参与 include（Makefile 依据 `OS=Windows_NT` 自动切换）。

## 3. 运行

必须在**工程根目录**运行，否则找不到 `gameserver.ini` 与 `data/`：

```bash
./build/GameServer
```

启动输出示例：

```
已加载配置 gameserver.ini
监听地址 0.0.0.0:7100
  GameServer 已启动（重建骨架）
  输入 help 查看命令，exit 退出
```

## 4. 数据格式

### `data/baseitem.txt`

每行一件物品模板，20 个基础字段 + 2 个可选药品字段，`/` 分隔，`#` 开头为注释：

```
名字/stdmode/shape/image/specialpower/ac1/ac2/mac1/mac2/dc1/dc2/mc1/mc2/sc1/sc2/weight/maxdura/price/needtype/needlevel/[使用类型 1=回HP 2=回MP]/[回复值]
```

### `data/maps/logic/*.ini`

```ini
[define]
name=中州
title=中州
blockmap=map0
type=1
areawidth=32      ; 每个区域包含的格数
areaheight=32
```

### `data/maps/physics/*.nmp`

原版为二进制，快照无格式说明；重建为等价文本：

```ini
[map]
name=map0
width=512
height=512
[block]
0=111111...   ; 第 0 行，1 表示阻挡；缺省行视为全部可通行
```

`tools/gen_sample_map.py` 可重新生成示例地图。

### `data/monsters.txt`

```
# 名字/最大HP/最小攻击/最大攻击/防御/经验/掉落物品/掉落概率(0-100)/等级/外形
鸡/30/1/3/0/10/金创药/50/1/0
```

### `data/spawns.txt`

```
# 地图id/x/y/数量/怪物名（坐标在 ±2 格内随机）
1/470/240/6/鸡
```

### `data/classes.txt`

```
# id/名称/HP成长/MP成长/最小攻击/最大攻击/最小防御/最大防御/魔法/道术/负重成长
0/战士/60/10/2/3/1/2/0/0/10
```

### `data/levels.txt`

```
# 等级/升到下一级所需经验（近似传奇世界曲线，可自行调整）
1/110
2/470
```

### `data/skills.txt`

```
# id/名称/职业/需要等级/消耗MP/冷却(ms)/威力/类型(1物理 2魔法 3治疗 4道术)/射程
3/火球术/1/1/8/1500/15/2/6
```

### `data/npcs.txt`

```
# 名字/地图id/x/y/类型(1商店 2传送)/目标地图/目标x/目标y/对话
杂货商/1/477/215/1/0/0/0/欢迎光临中州杂货铺，要买点什么？
传送员/1/480/230/2/2/200/200/要去落霞岛吗？
```

### `data/quests.txt`

```
# id/名称/发布NPC/类型(1杀怪 2收集)/目标/数量/经验/金币/奖励物品/数量/需求等级/对话/[前置任务id]/[可重复]
1/除害/杂货商/1/鸡/10/500/100/金创药/3/1/最近鸡太多了，帮我消灭10只鸡。
```

### `data/shop.txt`

```
# 物品名/售价
金创药/50
木剑/300
```

### `data/players/*.dat`

角色存档（`CPlayerStore` 写入）：文件头 `GSDB01` + 版本 + `CHARDBINFO` +
背包物品 + 装备位物品。二进制结构，随源码版本演进；损坏或版本不符时按“新角色”处理。

| 项目 | 结果 |
|---|---|

| 启动 | 加载 ini、地图、物品表，监听 7100 |
| 协议 | 客户端进图收到 8 个编码包（`SM_SETMAP`…`SM_UPDATEPROP`），已解码核对 |

## 6. 已知限制

1. **不能直连 2005 年真实客户端**：`SM_*` 数值、消息加密、封包结构均是按用法重建的；接入真实客户端需替换 `public.cpp` 中的 `_CodeGameCode` 与协议常量。
2. **SC/DB 仍是桩**：`CSCClientObj`/`CDBClientObj` 只打日志；持久化改用本地 `data/players/*.dat`，并非真实 DB 服务器协议。
3. **玩法深度有限**：怪物只有“被攻击后追击 + 近身普攻”，没有寻路；行会仓库无权限细分（成员均可存取）；活动需要手动开启。
4. **单线程 select 循环**：够用，但不是生产级网络层。
5. **物理地图为文本格式**：与真实 `.nmp` 二进制不兼容。
6. **存档为本地二进制结构**：不兼容任何历史 DB 表结构，换版本需迁移。
7. **等级与技能仍是近似实现**：最高 50 级，经验曲线是近似值；只有 6 个技能，技能书仅商店有售。
8. **堆叠上限 99**：支持拆分/批量卖出，但没有拖拽操作；三张地图、一个商店、一个 Boss 刷新点。
9. **存档格式随版本变化**：当前为 `GSDB11`（含强化/附魔/成就），旧存档会被当作新角色。
10. **Windows 构建脚本未实测**（本机只有 macOS 工具链）。

- 网页 `/cmd` 必须带 `X-Token`

- 密钥流：`SHA256(token + 小端 counter)`，按字节异或

## 85. 优雅停服与断线重连

- GameServer 注册 SIGTERM/SIGINT：
  - 请求主循环退出
  - 走 `Stop()` → 客户端 `OnDisconnect()` 存档 → `CleanServer()` 保存全部数据
- 996 启动器停服时先向 GameSrv 控制台写入 `exit`，最多等待 4 秒保存，再终止其它进程
- 客户端 `GameClient.connected` 标记连接状态
- 桌面客户端检测到断线后自动返回登录界面，提示重新登录

验证：

- 在线角色通过 `exit` 停服，角色存档由 OnDisconnect 保存
- 回归 176 项通过
